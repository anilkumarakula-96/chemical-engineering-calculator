Chemical Engineering Calculator

About the Project

This project uses Python to perform basic Chemical Engineering calculations.

The first program calculates the heat required to increase the temperature of a fluid.

Engineering Equation

Q = m × Cp × (T2 − T1)

Where:

- Q = Heat required (kJ)
- m = Mass of the fluid (kg)
- Cp = Specific heat capacity (kJ/kg·K)
- T1 = Initial temperature (°C)
- T2 = Final temperature (°C)

Example Calculation

Given:

- Mass = 100 kg
- Specific heat capacity = 2 kJ/kg·K
- Initial temperature = 30°C
- Final temperature = 80°C

Calculation:

Q = 100 × 2 × (80 − 30)

Heat required = 10,000 kJ
